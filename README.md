# Phishing Detector

A URL phishing detector with a FastAPI backend and a Chrome extension. The API checks URLs against a trusted-domain list and a locally generated live-threat cache, optionally queries Google Safe Browsing, and then uses a trained machine-learning model to estimate risk.

## Features

- URL-only model inference; the API does not need to open the page being checked.
- Risk levels: `safe`, `suspicious`, or `dangerous`.
- Optional Google Safe Browsing checks using an API key supplied through an environment variable.
- Optional live phishing-feed cache generated by `ml/live_updater.py`.
- Chrome extension that checks the active tab through the local API.

## Project layout

```text
api/                FastAPI application
extension/          Chrome extension (Manifest V3)
ml/models/          Trained model, scaler, and feature list
ml/data/raw/        Local training datasets (not tracked by Git)
ml/data/processed/  Local processed datasets (not tracked by Git)
ml/                 Training and live-feed update scripts
tests/              Project tests
```

The trained model files in `ml/models/` are included in the repository. Raw and processed datasets are intentionally excluded; for example, `ml/data/raw/dataset_2026.csv` is too large to store in a regular GitHub repository. Obtain the datasets separately if you need to retrain the model.

## Requirements

- Python 3.11 or newer
- The dependencies listed in `requirements.txt`
- Google Safe Browsing API key (optional; only needed for that check)
- Google Chrome (for the browser extension)

## Run the API locally

From the repository root, create and activate a virtual environment, then install dependencies:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Start the API:

```powershell
python -m uvicorn api.predict_api:app --reload --host 127.0.0.1 --port 8000
```

The API documentation is available at <http://127.0.0.1:8000/docs>, and the health endpoint is <http://127.0.0.1:8000/health>.

To enable Google Safe Browsing, set your own API key before starting the API. Do not commit the key:

```powershell
$env:GOOGLE_API_KEY = "your-api-key"
```

Without this variable, the API skips the Google Safe Browsing check and continues with the other detection layers.

### Check a URL

Send a `POST` request to `/predict` with a JSON body:

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/predict `
  -Method Post `
  -ContentType "application/json" `
  -Body '{"url":"https://example.com"}'
```

The response includes the normalized URL, a phishing boolean, confidence, risk level, explanatory signals, and the detection source.

## Install the Chrome extension

1. Start the API locally as described above.
2. In Chrome, open `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the repository's `extension` folder.
5. Visit a website and select the Phishing Detector toolbar icon to view its result.

The extension currently calls `http://127.0.0.1:8000`; it is configured for a locally running API.

## Refresh the live phishing cache

The API can use `ml/models/live_phishing_urls.json` when the file exists. This generated cache is intentionally ignored by Git. To refresh it, run the updater from the repository root:

```powershell
python ml/live_updater.py
```

The updater repeatedly fetches available feeds and refreshes the cache every 30 minutes. Stop it with `Ctrl+C`. Feed availability may vary. After creating or refreshing the cache, call `POST /reload-cache` to load it into an already-running API process.

## Training data and model

Training datasets belong under `ml/data/raw/` and processed outputs under `ml/data/processed/`; neither directory is committed. The scripts in `ml/` use these local files to explore data and train models. The trained model, scaler, feature list, and evaluation metrics used by the API are stored in `ml/models/`.

To retrain the API-compatible URL-only model from the repository root, run:

```powershell
python ml/step3_mega_train.py
```

This script reports held-out accuracy and class metrics, then saves the model, feature list, and evaluation details to `ml/models/`. The latest run trained on 685,418 unique URLs and achieved **98.02% accuracy** on a stratified random 80/20 split (137,084 test rows). A random split can share patterns or domains across training and test data, so this result may overstate performance on entirely new domains. Treat it as an evaluation on this dataset, not a guarantee of real-world accuracy.

## Important

This project is for educational and research use. Automated URL classification can produce false positives and false negatives; do not treat its output as a guarantee that a website is safe.
